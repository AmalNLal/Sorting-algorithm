# Sorting Algorithms

A collection of Jupyter notebooks that demonstrate classic sorting algorithms with Python implementations and explanations.

## Algorithms included

- [Bubble Sort](./1.Bubble%20sort.ipynb)
- [Selection Sort](./2.%20Selection%20sorting.ipynb)
- [Insertion Sort](./3.insertion%20sort.ipynb)
- [Merge Sort](./4%20merge%20sort.ipynb)
- [Quick Sort](./5%20quick%20sort.ipynb)

## Getting started

1. Clone this repository:
   ```bash
   git clone https://github.com/AmalNLal/Sorting-algorithm.git
   cd Sorting-algorithm
   ```
2. Open the notebooks with [Jupyter Notebook](https://jupyter.org/) or [JupyterLab](https://jupyter.org/).
3. Run the cells to explore each sorting algorithm.

## Purpose

These notebooks provide a visual and practical introduction to how common sorting algorithms work, making it easier to compare their approaches and understand their implementations.
