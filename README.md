# Sorting Algorithm Visualizations

This repository contains Jupyter notebooks that demonstrate and visualize classic sorting algorithms using Python and Matplotlib.

## What this project includes

- Step-by-step sorting demonstrations
- Visualization of sorting behavior
- Basic runtime measurement examples
- Random input generation for testing algorithm behavior

## Algorithms covered

1. **Bubble Sort** — `1.Bubble sort.ipynb`
2. **Selection Sort** — `2. Selection sorting.ipynb`
3. **Insertion Sort** — `3.insertion sort.ipynb`
4. **Merge Sort** — `4 merge sort.ipynb`
5. **Quick Sort** — `5 quick sort.ipynb`

## Requirements

- Python 3.8+
- Jupyter Notebook or JupyterLab
- Matplotlib

Install dependencies:

```bash
pip install matplotlib notebook
```

## How to run

1. Clone the repository.
2. Open the project folder.
3. Start Jupyter:

```bash
jupyter notebook
```

4. Open any notebook from the list above and run the cells in order.

## Learning goal

This repository is intended as a beginner-friendly reference for understanding how common sorting algorithms work and how their behavior can be visualized.
